# Power BI report

`Customer_Offer_Prediction.pbix` is the native four-page Power BI report authored in Power BI Desktop and opened successfully by the project owner.

Pages: Campaign Overview; Customer Analysis; Prediction & Model Performance; Business Insights & Recommendations.

Report screenshots live in [`../Screenshots/`](../Screenshots/).

`TestPredictions.csv` and `ModelMetrics.csv` support the ML visuals. `CampaignContacts` is sourced from `../outputs/powerbi_campaign_contacts.csv`. On another machine, use Power BI Desktop > Transform data > Data source settings to update local CSV paths if necessary.

The HTML preview is a separate demonstration, not the `.pbix` file. The native report was saved in Power BI Desktop; review the included screenshots or open the report in Power BI Desktop to inspect the pages.
